# Total Serialism Algorithm Test Matrix

This document tracks the standardization and feature completion status for all 50 algorithms in the Total Serialism pen plotter art collection.

## Testing Checklist

For each algorithm, verify:
- **SVG Export**: Can export clean SVG files suitable for pen plotting
- **PNG Export**: Can export raster preview images
- **Presets**: Has built-in presets or community presets available
- **Collapsible**: Control groups are collapsible for better UX
- **URL Persistence**: Parameters persist in URL for sharing
- **Position Controls**: Has centerX, centerY, rotation, scale controls
- **Auto-Regenerate**: Interactive controls trigger live regeneration

## Testing Procedure

For each algorithm:

1. **Manual Testing**
   - Open in browser
   - Adjust all controls
   - Test each preset
   - Verify exports work

2. **Code Review**
   - Check for position controls
   - Verify auto-regenerate flag
   - Confirm preset structure
   - Validate export functions

3. **Documentation**
   - Update this matrix
   - Note any issues
   - Document special features

4. **Standardization**
   - Run standardize-algorithms.py
   - Verify changes
   - Test functionality
